# Agent instructions

Read and follow `CONTRIBUTING.md` before changing this repository. It is the source of truth for contribution, validation, commit and merge rules. Read `DEPLOYMENT.md` before changing deployment configuration.

Keep changes small and focused. Run `npm run check` before considering code changes complete. For proxy or container changes, build the Docker image and verify its health check. Never persist or expose an Abraxio token, production response, personal data or confidential financial data.
